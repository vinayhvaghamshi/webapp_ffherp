1. ENDPOINT
================================================================================
  Base URL   : https://api.ffherp.co.in/api/
  Path       : Webhook/IncomingWebhookForProspect
  Method     : POST
  Headers    : Content-Type: application/json
  Success    : the response body is exactly the text  SUCCESS   (HTTP 200)
  Failure    : any other body, any non-2xx status, a network error, CORS
               rejection, or no response within 15 seconds.

  CORS verified 2026-10-06 from Origin https://vinayhvaghamshi.github.io :
      access-control-allow-origin: *
      access-control-allow-headers: content-type
  so the browser can call the endpoint directly (no proxy needed).

  function formatDate(date) {
      var year = date.getFullYear();
      var month = String(date.getMonth() + 1).padStart(2, '0');
      var day = String(date.getDate()).padStart(2, '0');
      return year + '-' + month + '-' + day;
  }

      }

  Notes on the port to the React app:
    * The endpoint, headers, payload keys, values and the "SUCCESS" check are
      unchanged. jQuery is not used — the same request is made with fetch().
    * alert() is replaced by the site's own toasts and inline messages so the
      visitor is not interrupted; the branch logic (SUCCESS vs not) is the same.
    * A 15 second timeout was added so a hanging request cannot lock the form.
    * The visitor's form is only cleared after a SUCCESS answer; on failure the
      typed values stay put so they can retry.

6. BEHAVIOUR ON RESPONSE
================================================================================
  body === "SUCCESS"            Signup : toast "Your 7-day free trial is ready!"
                                        + form reset + CRM activity log entry
                                Chat   : success card + "Start a new chat"
  anything else / non-2xx       Inline message "We could not save this just now.
                                Please try again." + toast with status/body.
                                The form keeps the typed values.
  network / CORS / timeout      Inline message "The server did not respond.
                                Please try again." (timeout after 15s)
  Local back-up                 Successful submissions are also kept in the
                                browser (ffh_signups / ffh_support_threads) purely
                                to power the "Saved details" auto-fill in the chat
                                widget. The CRM remains the system of record.
